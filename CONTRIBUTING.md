# Contributing to Binary Multiplier Simulator

First off, thank you for considering contributing! This tool aims to help computer science and engineering students globally, and your help makes it better.

## 💡 Where We Need Help

Here are a few high-impact features you could add:

- **Export to CSV/PDF:** Allow users to download the step-by-step table.
- **Division Algorithms:** Implementing Restoring and Non-Restoring division.
- **Dark Mode:** A toggle for better late-night studying accessibility.
- **Floating Point:** Adding IEEE-754 multiplication algorithms.

## 🛠️ How to Contribute

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine.
3. **Create a branch** for your feature or bug fix:
   `git checkout -b feature/your-feature-name`
4. **Make your changes** and ensure the logic doesn't break existing algorithms (test signed vs. unsigned edge cases!).
5. **Commit your changes** with descriptive commit messages:
   `git commit -m "Add export to CSV functionality"`
6. **Push to your fork:**
   `git push origin feature/your-feature-name`
7. **Open a Pull Request (PR)** against our `main` branch.

We will review your PR as soon as possible. Thank you!
